# Team Roles

Fill in names/handles. One person can hold several roles; every role has **one accountable owner**.

| Role | Owner | Accountable for |
|---|---|---|
| Project Lead / Product | _@handle_ | Scope, priorities, contract freeze, final calls |
| Frontend Lead | _@handle_ | `momo-guardian-frontend` |
| Backend / Risk Engine Lead | _@handle_ | `momo-guardian-api` |
| Data / Simulator Lead | _@handle_ | `momo-guardian-simulator`, calibration |
| Design & Brand | _@handle_ | Logo, UI polish, brand kit |
| Docs & Pitch Lead | _@handle_ | Docs hub, deck, demo script, submission |
| QA / DevOps (can be shared) | _@handle_ | CI, deployment, fallback, bug bash |

## Working agreements
- Decisions in writing (issue/ADR), not only in chat.
- Blockers raised within 1 hour, not at standup.
- Everyone reviews at least one PR a day.
- Submission owner: Docs & Pitch Lead; backup: Project Lead.
