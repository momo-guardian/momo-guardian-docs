# Definition of Done

**A task is done when:**
- Meets acceptance criteria in the issue
- Follows the API contract / scoring spec
- Has tests (engine code: unit tests required)
- Reviewed & approved; CI green; merged to `dev`
- Docs updated if behavior or setup changed
- Demonstrated (screenshot/recording/curl) in the PR

**A phase is done when** its "Exit" line in `execution-plan.md` is demonstrably true.
