# Differentiation

| Typical fraud system | MoMo Guardian |
|---|---|
| Detects unauthorized fraud | Targets **authorized-but-manipulated** payments |
| Acts after the fact | Acts **before** money leaves |
| Black-box block/allow | **Explainable** score + reasons |
| Blanket friction | **Risk-proportional** step-up |
| Closed, bank-side | **API-first**, pluggable into any platform |
| Ignores user psychology | **Smart questions** surface manipulation signals |

## Moat (honest view)
Short term: UX + explainability + speed to integrate. Long term: network effects from shared scam
intelligence (reported numbers/patterns across platforms) — a stretch goal, pitch as roadmap only.
